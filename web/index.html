How it was
kept fair.

  1. Same practice.

    Equal steps, same settings, same starting brain.

    100,007,936 steps for both · the same Zoo hardcore settings · the same starting weights, checked weight by weight

  2. Three runs each.

    One lucky run can’t decide it.

    Training seeds 42, 142 and 242 for every robot

  3. Hidden courses, used once.

    The test plan was locked before the test.

    Committed to git before the final test; the test script refuses to run twice or with uncommitted files

  4. Paired statistics.

    Same courses for both. Nothing “proven” without a test.

    McNemar’s exact test and the Wilcoxon signed-rank test on paired runs

  5. Bad results too.

    Failures, freezes and limits, shown like the wins.

    B’s safety check failed for 2 of its 3 runs · both robots learned to freeze at stumps · neither comes close to solving the course
