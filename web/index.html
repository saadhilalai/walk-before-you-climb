Method

How it was
kept fair.

  1. 01

    Same practice

    100,007,936 steps for both, the same settings, and the same starting brain, checked weight by weight.

  2. 02

    Three runs each

    Seeds 42, 142 and 242, so one lucky run can’t decide the result.

  3. 03

    Hidden courses, used once

    The test plan was committed to git before the test ran, and the test script refuses to run twice.

  4. 04

    Paired statistics

    Both robots on the same courses; McNemar and Wilcoxon tests. Nothing is called proven without one.

  5. 05

    Bad results too

    B’s safety check failed for 2 of its 3 runs. Both robots learned to freeze at stumps. Neither comes close to solving the course.
